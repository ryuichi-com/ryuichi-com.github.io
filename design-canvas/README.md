# トップページの方向案（デザイン検討用）

サイト本体（`../physio-ryu-tokyo/`）とは別の、デザイン方向を決めるための検討ファイルです。
ここのファイルは公開サイトには含まれません。

| ファイル | 内容 |
|---|---|
| `Main.dc.html` | 案B｜身体の図版（現時点の推奨） |
| `ClinicalRecord.dc.html` | 案A｜臨床の記録 |
| `MuseumSignage.dc.html` | 案C｜美術館のサイン |
| `canvas.json` | 3案の並び順と、各案の狙い・弱点の付箋 |

コピーは3案とも同一にしてあります。違いがデザインだけになるようにするためです。

## 現行デザインに戻すには

方向案を採用しない場合、サイト本体は触っていないのでそのままです。
もし本体を変更したあとで戻したくなった場合：

```bash
git checkout d5d28bb -- physio-ryu-tokyo/
```

`d5d28bb` は「紙と墨」版（Zen Old Mincho／彩度はCTAのみ／ヒーローは4工程の図）の最終コミットです。
