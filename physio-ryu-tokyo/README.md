# Physio Ryu Tokyo ウェブサイト

理学療法士による完全予約制パーソナルスタジオ「Physio Ryu Tokyo」の静的サイトです。

**現時点では未公開です。** 全ページに `noindex, nofollow` が入っています（外し方は後述）。

```

├── about/                  新井りゅうについて
```

`http://localhost:8000/` を開いてください。

## 写真の差し替え方

現在、写真はすべてプレースホルダです。**枠の中に「何を撮るか」を書いてあります。**
ブラウザで開くと、各枠に用途名と撮影内容が表示されるので、
それを見ながら撮影してください。撮影指示はHTMLを読まなくても画面上で確認できます。

画像ファイルを `images/` に置き、枠の中の `<span class="ph__label">…</span>` を
`<img>` に丸ごと差し替えるだけで反映されます。

差し替え前：

```html
<figure class="ph ph--portrait ph-face">
  <span class="ph__label">
    <span class="ph__name">新井りゅうの顔写真（縦長・3:4）</span>
    <span class="ph__brief">上半身、正面かやや斜めから。…</span>
  </span>
</figure>
```

差し替え後：

```html
<figure class="ph ph--portrait ph-face">
  <img class="ph__img" src="../images/face.jpg" alt="新井りゅう">
</figure>
```

（トップページからは `images/face.jpg`、下層ページからは `../images/face.jpg`）

CSSフィルターや加工は一切かけていません。顔写真は正方形か縦長のまま使ってください
（円形トリミングにしない方針です）。

### いま入っている仮の写真

**すべて仮置きです。撮影が済んだら差し替えて、`tmp-` のファイルは削除してください。**

**この状態で公開してはいけません。** 実在しない人物の写真を治療院のサイトに載せることになります。

### 本物の写真

`images/seminar-01.jpg` と `seminar-02.jpg` は**実際のセミナーの記録**です。仮置きではありません。
受講者の顔は、ご本人の特定を避けるため撮影者側で隠してあります。

- `profile-side.jpg` — 新井りゅうについて「なぜこの場所を始めたのか」に掲載中。

### 掲載しなかった写真について

依頼者から、学会の表彰・公開講座の集合写真・研修修了証の3枚も提供されましたが、
**掲載していません。**いずれも笑顔の記念写真で、このサイトのトーンと合わないためです。

判断の理由は「実績の証拠として弱いから」ではありません。むしろ逆で、
**証拠としては強いが、見せ方が競合と同じになるから**です。
表彰状を掲げた写真は、権威を見せる定番の構図です。
このサイトは「すごい先生だ」で終わらせず「一度見てもらいたい」と思わせることを
目標にしているので、実績の陳列は目標と逆に働きます。

受賞・研修修了・講師の事実は、すべて「資格・実績」に文字で記載済みです。

**まだ埋まっていないのは3枠**（建物の外観・入口・地下へ下りる階段）。
実在の建物なので生成では代用できません。枠の中に撮影内容が表示されたままです。

公開前の確認：

```bash
grep -rn "tmp-" --include=*.html .   # 何も出なければOK
```

## デザイン上の設計判断（変更前に読んでください）

見た目の「定石」で上書きすると、このサイトの目的が壊れます。

| 設計判断 | 理由 |
|---|---|
| プロフィールが第4セクション（前半） | 価格の根拠を「誰が見るか」に置いている。根拠が結論より後ろにあってはならない |
| ④プロフィール → ⑤整理してお伝えすること → ⑥料金 の順 | 「誰が見るか（根拠）→ 何が手に入るか（対価）→ いくらか（価格）」を連続させている。以前は根拠と価格が7画面離れていて、読者は根拠を忘れた頃に値段を見ていた。**この3つの順序を崩さないこと** |
| ファーストビューに価格と「木曜日のみ」を出す | 枠が週1日しかないため、来訪者数より適合率を優先する。合わない方に11画面スクロールさせない |
| 価格の横に書くのは「ご予約枠60分」 | 60分行うことは約束していない（料金セクション本文で「短時間で終えた方がよい場合もある」と書いている）。「原則60分」と書くとこの文と矛盾する |
| CTAは「LINEで相談・予約する」 | LINEでは予約が確定せず、可否を確認する工程が先にある。「予約する」だけでは実際の動作と一致しない |
| 見出しが明朝体（Zen Old Mincho） | ゴシックのみだと整体院サイトの見た目になり、価格の説得力が落ちる |
| 金色・筆記体・装飾アイコンを使わない | 美容サロンの記号。美容文脈で読まれると16,500円の意味が変わる |
| ネガティブ情報（地下・階段・待合なし）を隠さない | 誠実さが最大の差別化。ミスマッチな問い合わせも減る |
| 動きは「現れる」だけ。拡大・回転・視差は使わない | 落ち着いた信頼を売る事業。動きが目に付いた瞬間に安く見える |
| LINEのボタンに `target="_blank"` を付けない | 別タブで開くと、InstagramやLINEの内蔵ブラウザでは開かないことがある。アプリが起動したあとに空のタブも残る |
| 料金は価格が主・時間は補足 | 「16,500円／60分」と並列にすると時間単価で比較され、相場8,000〜12,000円の競合に負ける |

### デザインシステムの6つの規律

`css/style.css` の冒頭に同じ内容を書いてあります。**この6つを崩すと、
「どこにでもある落ち着いたサイト」に戻ります。**

**1. 紙と墨。彩度を持つのは押すべきボタンだけ。**

地には和紙の質感（`images/washi.png`）を敷いています。256pxのタイルを
`background-blend-mode: multiply` で地色に掛けているので、`--paper` でも
`--paper-deep` でも同じ質感が乗ります。**墨の面には掛けません**
（暗い地の上ではノイズか汚れに見えるため）。

濃さを変えるときは**画像を差し替えてください**。CSSの数値ではありません。
ただし濃くしすぎると、副次テキスト（`--ink-sub`）のコントラストが
4.5:1 を割ります。現在は最も沈む濃い紙の上で 4.54:1 とぎりぎりです。

地は生成りの紙、文字は暖かい墨。サイト全体で彩度のある色は **LINEグリーン ただ一つ**です。
「色が付いている＝そこを押す」という規律。装飾のために差し色を足さないでください。
無彩色はすべて墨（`#23211E`）から導いた暖色寄りのグレーで、
寒色のグレー（`#6B7280` など）を混ぜると紙の温度と合わなくなります。

**黒い面は1ページに2回まで。短く大きい文字のときだけ。**
トップページでは2枚使っています。③の「同じ身体でも、見る人が変われば、やることが変わります。」
（`.quote-plane`）と、⑩の最終CTA（`.section--ink`）です。
紙 → 黒 → 紙と切り替わることで、その一文だけが浮き上がります。
**3枚目を足した瞬間に効果が落ちます。**

黒にしない場所：免責・注意事項・FAQ・料金の細かい条件・建物の説明。
このサイトはネガティブ情報を隠さないことが最大の差別化なので、
告知を黒地に白抜きで置くと演出に見えてしまいます。
主軸が40〜50代であることも理由です（黒地の長文は読みにくい）。

**2. セクションを区切るのは、余白の落差と見出しの級数だけ。**
1セクションおきに背景色を変える処理は使いません。
章番号や章題のラベルも置きません。見出しと重複して、
小さな見出しが二重に並ぶだけになるためです。

**3. セクションに軽重をつける。**

| クラス | 用途 | 効果 |
|---|---|---|
| `.section--major` | 章の山場（③なぜ戻るのか、④プロフィール） | 見出しが大きく、余白が広い |
| `.section` | 標準 | |
| `.section--minor` | 補足的な章（FAQ、資格一覧） | 見出しが小さく、余白が詰まる |
| `.section--plane` | 内容の質が違う章（⑤整理してお伝えすること、⑧疾患後の管理、免責） | 紙の面が変わる |
| `.section--ink` | 最終CTA | 墨地。1ページに1回まで |

全部を同じ大きさで並べると、どこが山場か読者に伝わりません。

**4. 寸法はスケールから取る。その場かぎりの数値を書かない。**
文字は `--fs-xs 〜 --fs-4xl`（1.25倍の9段階）、余白は `--sp-1 〜 --sp-10`（4px基準の10段階）。
行間も `--lh-read`（読ませる 1.9）と `--lh-tight`（実務情報 1.65）を使い分けます。
全部が同じ行間だと緩急が消えて、締まりのない紙面になります。

**5. 本文に `<br>` を入れない。折り返しはブラウザにそろえさせる。**
日本語は語の途中でも折り返してしまうため、放っておくと
「回復期リハビリテーシ／ョン。」のように行末が割れます。
`<br>` で行を固定すると、その行が画面幅より長いときに必ず端数が出て、
今度は「す。」「を、」のような1〜2文字の行が生まれます。**スマホでは必ずこうなります。**

そこで、折り返しはCSSに任せています（`css/style.css` の「2. リセット / 基本」）。

| 指定 | 効果 |
|---|---|
| `word-break: auto-phrase` | 文節の切れ目で折り返す。語の途中で割れない（Chrome / Edge） |
| `text-wrap: pretty` | 最終行が極端に短くなるのを抑える（上の非対応ブラウザでの保険） |
| `text-wrap: balance` | 見出し・設問・箇条書きの各行の長さをそろえる |

`<html lang="ja">` が入っていないと `auto-phrase` は効きません。ページを追加するときは必ず入れてください。

`<br>` を使ってよいのは、**どの画面幅でも折り返さない短い行だけ**です。
ヒーローの主コピー、引用（`.pull-quote`）、住所・営業時間のような箇条。
それ以外の場所で行を切りたくなったら、次のどれかを使ってください。

| クラス | 使いどころ |
|---|---|
| `.u-br-pc` | パソコンでだけ改行する（スマホでは自然な折り返しに任せる） |
| `.u-br-sp` | スマホでだけ改行する |
| `.u-nw` | 「Level Ⅰ・Ⅱ・Ⅲ」のように、途中で切れると読みが崩れる**短い**かたまり |

`.u-nw` を長い文に付けると横スクロールが出ます。必ず画面幅より短いものに限ってください。

見出しの文字サイズ（`--fs-xl` / `--fs-2xl` / `--fs-3xl` / `--fs-hero`）の**下限側は、
スマホでの折り返しから逆算した値**です。上限（パソコンでの見え方）はスケールどおりなので、
下限を上げると、スマホで見出しが3行に割れて崩れます。

修正後は `tools/check-line-breaks.mjs` で全ページ・全画面幅をまとめて確認できます。
実際に描画された1行ずつを測って、極端に短い行と横スクロールを報告します。

```bash
npm install playwright && npx playwright install chromium
python3 -m http.server 8765          # 別のターミナルで
node tools/check-line-breaks.mjs
```

サイトの動作にこのスクリプトは不要です。文章を書き換えたあとの確認だけに使います。

**6. 動きは「現れる」だけ。**
`.reveal` を付けた範囲の**中身ひとつずつ**が、画面に入った順に現れます。
範囲ごとにまとめて出すのではないので、スクロールの速さがそのまま出方になります。

| 対象 | 動き |
|---|---|
| 文字・囲み | にじみ（`blur(4px)`）が取れながら、下から20px上がってくる |
| 写真（`.ph`） | 地と同じ色の覆いが上へ引き上げられ、下から画が現れる（1.5秒）。中の画像はわずかに縮みながら収まる |
| 罫（`.rule`） | 左から引かれる。ここはにじませない（1pxの線はぼかすと消えて見えるため） |

**「ふわっ」の正体は、濃さと位置の長さが違うことです。**
濃さとにじみは1秒（`--dur-reveal-fade`）で終わり、位置は1.4秒（`--dur-reveal`）かけて収まります。
先に読める状態を作ってから、そのあと静かに位置が落ち着く。
**同じ長さにすると、ただ遅いだけの動きになります。**

**速さを変えたいときは、長さより先に曲線を見てください。**
出足の速い曲線だと、1秒かけても最初の0.2秒で半分まで濃くなり、残りは見えないところで終わります。
長さを伸ばしても「ゆっくり」にはなりません。
いまは `--ease-reveal` に `cubic-bezier(0.4, 0, 0.2, 1)` を使っています。実測値は次のとおりです。

| 経過 | 0.1秒 | 0.3秒 | 0.5秒 | 0.7秒 | 1.0秒 |
|---|---|---|---|---|---|
| 濃さ | 0.03 | 0.37 | 0.78 | 0.94 | 1.00 |

同じタイミングで画面に入ったものだけ、110ミリ秒ずつ遅らせて順に出します（最大4段）。
別々にスクロールインしたものは待たせません。待たされているように見えるためです。

ゆっくり出すぶん、`js/site.js` の `rootMargin` は `-5%` にしてあります。
深く入ってから出しはじめると、読む位置に来るまでに収まりきりません。

**拡大・回転・視差（パララックス）は使いません。** 動きが演出として目に付いた瞬間に、
16,500円の根拠を語るサイトではなくなります。
にじみを4pxより強くするのも避けてください。文字が読めなくなります。

写真の覆いの色は `--curtain` です。**面の色が変わる章では、その面の色に必ず上書きしてください。**
ずれていると、写真が出る瞬間に別の色の板が見えます
（`.section--plane` と `.section--ink` は設定済み）。

`.reveal-ready` と `.is-visible` を付けるのはJSです。**JSが動かない環境では最初から表示されたまま**になり、
`prefers-reduced-motion: reduce` の設定でも動きは出ません。内容は必ず読める状態を保ってください。

### 表現上の禁止事項（法務）

文言を書き換える際は、以下を使わないでください。

- 「マッサージ」「揉む」「ほぐす」— 国家資格を要する業と誤認させる表示は不適切
- 「整体」を見出しやサービス名に使う — FAQの比較文脈でのみ可
- 「ここでリハビリを行う」— 「リハビリ」は過去の経験を語る文脈でのみ
- 「治る」「根本改善」「矯正」「正常化」「効果があります」— 治療効果の断定・誇大表現
- 診断的な表現全般 — 診断は医師の領域

逆に、以下は必ず残してください。

- 「ここで行うのは治療ではありません」
- 「医療機関の受診や治療に代わるものではありません」
- 「主治医の治療方針を最優先します」
- 「安全に対応できないと判断した場合は、お断りすることがあります」
