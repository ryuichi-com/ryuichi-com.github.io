# Physio Ryu Tokyo ウェブサイト

理学療法士による完全予約制パーソナルスタジオ「Physio Ryu Tokyo」の静的サイトです。

**現時点では未公開です。** 全ページに `noindex, nofollow` が入っています（外し方は後述）。

---

## ファイル構成

```
physio-ryu-tokyo/
├── index.html              トップページ（10セクション）
├── after-treatment/        疾患後の身体管理
├── about/                  新井りゅうについて
├── first-visit/            はじめての方へ
├── access/                 アクセス・ご予約
├── legal/                  特定商取引法に基づく表記
├── privacy/                プライバシーポリシー
├── css/style.css           全ページ共通のデザインシステム
├── js/site.js              ナビ開閉／フェードイン／固定CTA
└── images/                 画像（現在は空）
```

ビルドツールは不要です。`index.html` をブラウザで直接開けば動きます。
ローカルサーバで確認する場合は、このディレクトリで `python3 -m http.server 8000` を実行し
`http://localhost:8000/` を開いてください。

## 写真の差し替え方

現在、写真はすべてプレースホルダです。**枠の中に「何を撮るか」を書いてあります。**
ブラウザで開くと、各枠に用途名と撮影内容が表示されるので、
それを見ながら撮影してください。撮影指示はHTMLを読まなくても画面上で確認できます。

画像ファイルを `images/` に置き、枠の中の `<span class="ph__label">…</span>` を
`<img>` に丸ごと差し替えるだけで反映されます。

差し替え前：

```html
<figure class="ph ph--portrait ph-face">
  <span class="ph__label">
    <span class="ph__name">新井りゅうの顔写真（縦長・3:4）</span>
    <span class="ph__brief">上半身、正面かやや斜めから。…</span>
  </span>
</figure>
```

差し替え後：

```html
<figure class="ph ph--portrait ph-face">
  <img class="ph__img" src="../images/face.jpg" alt="新井りゅう">
</figure>
```

（トップページからは `images/face.jpg`、下層ページからは `../images/face.jpg`）

CSSフィルターや加工は一切かけていません。顔写真は正方形か縦長のまま使ってください
（円形トリミングにしない方針です）。

### 必要な写真の一覧（全18枠）

| 枠 | 場所 | 比率 |
|---|---|---|
| スタジオの空間 | トップ ファーストビュー | 16:9 |
| 新井りゅうの顔写真 | トップ④／新井りゅうについて | 3:4 |
| 聞く・見る・伝える・運動・再確認・セルフケア | トップ⑥ セッションの流れ（各1枚・任意） | 16:9 |
| 外観／入口／階段／室内 | トップ⑧／アクセス（同じ4枚を両ページで使用） | 4:3 |
| OGP画像 | `images/ogp.jpg` | 1200×630 |

**階段の写真だけは、見栄えより実物どおりであることを優先してください。**
ご利用の可否を判断していただくための写真なので、明るく補正しないでください。

## 公開までの運用

このサイトは開業まで公開しない前提です。以下のいずれかを想定しています。

### 1. ローカルのみで保管する（最も単純）

このリポジトリのブランチに置いたまま、開業時にアップロードします。

> **注意**：このリポジトリは GitHub Pages の公開リポジトリです。
> `main` ブランチにマージすると `https://ryuichi-com.github.io/physio-ryu-tokyo/` で
> 誰でも閲覧できる状態になります。`noindex` は検索結果に出さないだけで、
> URLを知っている人のアクセスは防げません。
> 完全に非公開にしたい場合は、次の 2 か 3 を選んでください。

### 2. アクセス制限付きでデプロイする

| サービス | 制限のかけ方 |
|---|---|
| Netlify | Site settings → Access control → Visitor access でサイト全体にパスワードを設定 |
| Cloudflare Pages | Cloudflare Access でメールアドレス認証を設定 |
| Vercel | Settings → Deployment Protection を有効化 |

いずれもこのディレクトリをそのままアップロードするだけで動きます（ビルド設定不要）。

### 3. プレビューURLのみで共有する

デプロイ先のプレビューURLだけを関係者に共有し、
本番ドメインは開業時に接続します。

## デザイン上の設計判断（変更前に読んでください）

見た目の「定石」で上書きすると、このサイトの目的が壊れます。

| 設計判断 | 理由 |
|---|---|
| プロフィールが第4セクション（前半） | 価格の根拠を「誰が見るか」に置いている。根拠が結論より後ろにあってはならない |
| 見出しが明朝体（Zen Old Mincho） | ゴシックのみだと整体院サイトの見た目になり、価格の説得力が落ちる |
| 金色・筆記体・装飾アイコンを使わない | 美容サロンの記号。美容文脈で読まれると16,500円の意味が変わる |
| ネガティブ情報（地下・階段・待合なし）を隠さない | 誠実さが最大の差別化。ミスマッチな問い合わせも減る |
| アニメーションはフェードインのみ | 落ち着いた信頼を売る事業。派手な動きは価値を下げる |
| 料金は価格が主・時間は補足 | 「16,500円／90分」と並列にすると時間単価で比較され、相場8,000〜12,000円の競合に負ける |

### デザインシステムの4つの規律

`css/style.css` の冒頭に同じ内容を書いてあります。**この4つを崩すと、
「どこにでもある落ち着いたサイト」に戻ります。**

**1. 紙と墨。彩度を持つのは押すべきボタンだけ。**
地は生成りの紙、文字は暖かい墨。サイト全体で彩度のある色は **LINEグリーン ただ一つ**です。
「色が付いている＝そこを押す」という規律。装飾のために差し色を足さないでください。
無彩色はすべて墨（`#23211E`）から導いた暖色寄りのグレーで、
寒色のグレー（`#6B7280` など）を混ぜると紙の温度と合わなくなります。

**2. 柱（はしら）で区切る。背景の塗り分けでは区切らない。**
セクションに `data-chapter="三" data-chapter-label="なぜ、戻るのか"` を書くと、
PC（1240px以上）では本文左の余白に、スマホでは見出しの上に柱が出ます。
雑誌の柱と同じ役割です。1セクションおきに背景色を変える処理は使いません。

**3. セクションに軽重をつける。**

| クラス | 用途 | 効果 |
|---|---|---|
| `.section--major` | 章の山場（③なぜ戻るのか、④プロフィール） | 見出しが大きく、余白が広い |
| `.section` | 標準 | |
| `.section--minor` | 補足的な章（FAQ、資格一覧） | 見出しが小さく、余白が詰まる |
| `.section--plane` | 内容の質が違う章（⑤疾患後の管理、免責） | 紙の面が変わる |
| `.section--ink` | 最終CTA | 墨地。1ページに1回まで |

全部を同じ大きさで並べると、どこが山場か読者に伝わりません。

**4. 寸法はスケールから取る。その場かぎりの数値を書かない。**
文字は `--fs-xs 〜 --fs-4xl`（1.25倍の9段階）、余白は `--sp-1 〜 --sp-10`（4px基準の10段階）。
行間も `--lh-read`（読ませる 1.9）と `--lh-tight`（実務情報 1.65）を使い分けます。
全部が同じ行間だと緩急が消えて、締まりのない紙面になります。

### 表現上の禁止事項（法務）

文言を書き換える際は、以下を使わないでください。

- 「マッサージ」「揉む」「ほぐす」— 国家資格を要する業と誤認させる表示は不適切
- 「整体」を見出しやサービス名に使う — FAQの比較文脈でのみ可
- 「ここでリハビリを行う」— 「リハビリ」は過去の経験を語る文脈でのみ
- 「治る」「根本改善」「矯正」「正常化」「効果があります」— 治療効果の断定・誇大表現
- 診断的な表現全般 — 診断は医師の領域

逆に、以下は必ず残してください。

- 「ここで行うのは治療ではありません」
- 「医療機関の受診や治療に代わるものではありません」
- 「主治医の治療方針を最優先します」
- 「安全に対応できないと判断した場合は、お断りすることがあります」
